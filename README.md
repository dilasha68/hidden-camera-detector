# SafeStay Hidden-Camera Awareness Guide

A small browser-based safety-awareness project that walks users through common visual inspection steps for hotels, bathrooms, and changing rooms.

## What it does

- Presents area-specific places to inspect
- Provides a manual inspection checklist
- Shares evidence-preservation and reporting guidance
- Runs entirely in the browser with HTML, CSS, and JavaScript

## Run locally

Open `index.html` in a browser. No build step or backend is required.

## Scope and safety

This project is an educational checklist, not a camera scanner or a guarantee that a room is safe. It does not inspect Wi-Fi networks, analyze images, or detect hardware programmatically. If you find a suspicious device, avoid touching it, preserve evidence, move to a safe location, and contact the property manager or local authorities.
